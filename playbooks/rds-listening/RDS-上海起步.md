# RDS 交通广播监听起步（上海）

> **适用**：RTL-SDR Blog **V4** (R828D, 24 MHz – 1.766 GHz) + 加载单极子天线，居家 SDR++ 监听 VHF FM 交通广播 + RDS 副载波
> **位置**：上海普陀（FM 发射塔多在市区，距你家 10-20 km 居多）
> **目标**：稳定听清上海交通广播语音 + 解出 RDS 副载波（电台名 / TA 交通信息 / 时间）
> **最后更新**：2026-08-05

---

## 0. RDS 是什么（一句话版）

RDS（Radio Data System）= **FM 副载波上的数字小频道**。FM 频段是 88-108 MHz，主载波两边各留 50 kHz 给立体声 + 数据；其中 **57 kHz 处**专门放了 RDS 数据，调制方式 BPSK，码率 1187.5 bps，传送：

- **PI**：电台唯一识别码（4 字节 16 进制）
- **PS**：电台名（8 字符，循环显示）
- **PTY**：节目类型（News / Pop / Traffic…）
- **TA / TP**：交通通告标志 / 交通节目标志（这就是"交通广播"两字的来源）
- **RT**：电台文本（滚动新闻 / 歌曲名）
- **CT**：时钟时间（电台发出来的校时信号）
- **AF**：替代频率（移动接收用）

听 FM 语音 = 解主载波；看 RDS 文字 = 多一道解调。SDR++ 自身**没有原生 RDS 解码**，需要插件或换软件，详见 §2.3。

## 1. 推荐频点

### 1.1 必听（开箱即有内容）

| 频点 | 部门 | 说明 |
|------|------|------|
| **FM 103.7 MHz** | 上海交通广播 | 主目标。**TA 必开**，每 15-30 min 一次路况播报（早晚高峰更密）。RDS PS = `上海交通广播` 或 `FM103.7` |
| **FM 93.4 MHz** | 上海新闻综合广播 | 整点新闻 + 偶尔插播路况。RDS PS = `上海新闻` |

### 1.2 重点扫频

**整段扫**：88.0 – 108.0 MHz，100 kHz 步进。**上海一共有 ~20 套 FM 节目**（含中央台、长三角周边），每套都有 RDS。

扫法：
- SDR++ 调到 2.4 MSPS sample rate，**一次能看 2.4 MHz 宽**
- 从 88 慢慢往上滚（鼠标滚轮），看到信号峰停下来听
- 信号强度排前 5 的频点记下来 → 那就是你能稳定收的本地台

| 频点（MHz） | 电台 | RDS PS（参考） | 备注 |
|------------|------|----------------|------|
| 87.9 | 苏州新闻 / 长三角 | — | 苏州方向，弱 |
| 90.9 | 东广新闻台 | `东广新闻` | 整点新闻 |

**查证方式**（频点会变，**用之前先核对**）：

1. radioReference.com → 搜 "Shanghai" / "FM"
2. 国内公众号 / ham 论坛搜"上海 FM 频率表"
3. SDR++ 整段扫，自己建一张表
4. 直接看你 SDR 里解出来的 **RDS PS** 字段（最准）

### 1.4 监听时段推荐

- **早 7-10**：FM 103.7 早高峰路况播报，**TA 触发最频繁**
- **晚 5-8**：晚高峰路况，**TA 触发第二密**
- **深夜 11-1**：音乐节目，RDS RT 字段滚动歌曲名 + 演唱者
- **任意整点**：93.4 新闻综合广播的整点新闻，**RDS CT 字段**最准（看 SDR 解出来的时间和手机对比）

## 2. SDR++ 参数配置

### 2.1 必配 4 项（核心）

| 参数 | 值 | 为什么这么配 |
|------|----|------------|
| **Mode** | **WFM**（宽带调频） | FM 广播国际标准，**必须 WFM**。NFM（窄带调频）只占 12.5 kHz，解不出 FM 立体声 + RDS 副载波 |
| **Bandwidth** | **200 kHz** | FM 信道 200 kHz 宽（±100 kHz 频偏 + 立体声 + RDS 副载波都在内）。**200 kHz 是标准**，少了会切掉立体声 / RDS |
| **Squelch** | **关**（−100 dB 或拉到最左） | 上海 FM 信号强，开了 Squelch 也能听；但**想看 RDS 必须关**——RDS 副载波在信号弱时会瞬时掉，Squelch 会把这种瞬时弱信号滤掉 |
| **Gain** | **0-20 dB 起步**（**比 ATC 低得多**） | **关键差异**：FM 广播发射塔在市区 10-20 km，**功率几十 kW**，信号比 ATC 强 60-80 dB。V4 tuner 高增益会削波。**起步 0-20 dB**，看到 −40 dBm 以上就降 |

### 2.2 强烈建议

| 参数 | 值 | 为什么 |
|------|----|------|
| **AGC** | **可以开** | FM 信号强度稳定（发射塔固定），不像 ATC 塔台 vs 飞机差 30 dB。AGC 开能自动适应小幅信号波动。**想看 RDS CT 校时建议关**（AGC 引入的时延会让 CT 解码不稳） |
| Sample Rate | 2.4 MSPS | 一次看 2.4 MHz 宽，覆盖一个 FM 频点 + 邻频，便于对比 |
| FFT Resolution | 2048 | 频谱分辨率 ~1.2 kHz 够用 |

### 2.3 RDS 解码（关键）

**SDR++ 截至目前没有原生 RDS 解码插件**。要看到电台名 / TA 标志 / 校时，得换软件或加外部解码器：

| 软件 | 平台 | RDS 支持 | 推荐度 |
|------|------|---------|--------|
| **SDR# (SDRSharp)** | Windows | ✅ 原生 | ⭐⭐⭐⭐⭐（最稳） |
| **SDRangel** | Windows / Linux / macOS | ✅ 原生 | ⭐⭐⭐⭐（功能多但重） |
| **CubicSDR** | macOS / Linux | ✅ 原生 | ⭐⭐⭐⭐（macOS 首选） |
| **GQRX** | Linux / macOS | ❌ 不支持 | ⭐⭐（听音 OK，RDS 拉胯） |
| **multimon-ng** | 命令行 | ✅ 单独解码 | ⭐⭐⭐（给 SDR++ 输出音频） |

**两套推荐路径**：

**路径 A：直接换 SDR# / CubicSDR**（推荐新手）
- Windows → SDR#（社区里最常用）
- macOS → CubicSDR（原生支持 RDS）
- 装好后在插件里开 RDS 解调器，屏幕上会出 PS / RT / TA / CT

**路径 B：SDR++ 听音 + multimon-ng 解码**（推荐 Linux / 命令行玩家）
- SDR++ 把音频输出到 virtual audio cable
- multimon-ng `-t raw -a SCOPE` / `-a RDS` 命令行解码
- 终端滚动打出 `PI=xxxx PS=xxxx RT=xxxx`

> 💡 **听语音** SDR++ 就够了。**要 RDS 文字**，花 10 分钟装 SDR# 或 CubicSDR 是最划算的。

## 3. 物理准备

### 3.1 天线

- **极化**：**垂直**（V4 出厂的 **loaded whip 单极子**，吸盘当"地"，单棒立着就是垂直极化）
  - **不用刻意摆姿势**，吸盘一吸、单棒指天就是对的
- **长度**：拉杆全伸约 **20-25 cm**（含底部 loading coil）
  - 物理上不到 λ/4（FM 段 λ/4 = 70-85 cm），靠**加载线圈**电学延长到 VHF 段谐振
  - 增益比偶极子**低 2-3 dB**，FM 段因偏离谐振再弱 1-2 dB
  - **但 FM 信号本来就强 60+ dB**，完全不影响听音；RDS 解码可能稍弱
- **位置**：吸盘吸在**朝市区方向的窗玻璃**上
  - 上海 FM 发射塔多在**市中心方向**（人民广场 / 静安一带），从普陀朝东南 / 东的窗能直对
  - 朝北窗也行（多个方向来的反射信号强度够）
- **离地高度**：窗边即可
- **吸盘"地"的坑**：窗玻璃**不导电**，吸盘当"地"效果差
  - 解决：吸盘下面**贴一片铝箔**（5-10 cm 见方），增大有效"地"面积
  - 或吸在**金属窗框**上（如果有）
- **离金属**：≥ 30 cm，避开金属窗框

### 3.2 同轴线

- 原装 3 米那根够用
- 远离 USB 3.0 数据线、电源线
- 不要卷成圈

### 3.3 削波警告

> ⚠️ **FM 信号比 ATC 强 60-80 dB**。ATC 要升 Gain 到 30-40 dB，**FM 反过来要降**。
> 削波后你听音不会立刻察觉（人耳对削波不敏感），但**频谱会出现肩膀**，RDS 解码会失败（误码率爆涨）。
> 看到频谱两侧冒起对称的小峰 = 削波，降 Gain 5 dB 再看。

## 4. 实操流程（按这个顺序来）

1. 打开 SDR++，Source 选 RTL-SDR USB
2. 频点输入 **103.700**（注意小数点 3 位），回车
3. Mode → **WFM**
4. BW → **200 kHz**
5. Squelch → 拉到最左（关）
6. Gain → **Manual 0 dB**（FM 信号强，从最低起步）
7. AGC → **可以开**（听音场景；要看 RDS CT 就关）
8. 看底部 dB 数：
   - 噪声底应在 **−110 ~ −100 dBm**
   - 103.7 信号峰应跳到 **−40 ~ −20 dBm**（**比 ATC 强 30-40 dB**）
9. 削波（频谱两侧冒小峰）→ 降 Gain 5 dB
10. 没信号 / 信号太弱 → 升 Gain 5 dB（一般到 20 dB 就够）
11. 听到立体声 + 偶尔播报路况 → FM 收听成功
12. 想看 RDS 文字 → 装 SDR# / CubicSDR 重做上面 12 步，屏幕会显示 PS / RT / TA

## 5. 排错

### 5.1 能听但没立体声

| # | 检查项 | 修复 |
|---|--------|------|
| 1 | BW 是不是 ≥ 150 kHz | 调到 200 kHz |
| 2 | Mode 是不是 WFM（不是 NFM / AM / LSB） | 改 WFM |
| 3 | 信号弱导致立体声 PLL 失锁 | 升 Gain 5 dB 或换窗边 |

### 5.2 频谱有信号但没声音

| # | 检查项 | 修复 |
|---|--------|------|
| 1 | 频点对不对 | 103.7 输成 10370 之类单位错 |
| 2 | Sample Rate 太小 | 调到 2.4 MSPS（BW 200 kHz 至少要这个 sample rate） |
| 3 | Audio 设备选错 | SDR++ Settings → Audio → Output 选对 |

### 5.3 有声音但没 RDS 文字

| # | 检查项 | 修复 |
|---|--------|------|
| 1 | **SDR++ 本身不支持 RDS** | 换 SDR# / CubicSDR，或加 multimon-ng |
| 2 | BW 是不是 200 kHz | 切到 ≤ 200 kHz 会切掉 RDS 副载波（57 kHz） |
| 3 | 削波了 | 频谱两侧有对称小峰 = 削波，降 Gain |
| 4 | 信号弱（RDS 副载波 SNR 不足） | 升 Gain 5 dB 或换窗边 |
| 5 | 频点没 RDS（不是所有台都开 RDS） | 试 103.7 / 93.4 / 90.9 这几个确认有 RDS 的台 |

### 5.4 信号太强削波

| # | 动作 |
|---|------|
| 1 | Gain 降到 0 dB |
| 2 | 还是削波 → 关 AGC（AGC 在过载时反而会乱） |
| 3 | 还是削波 → 在天线和 SDR 之间加一个 **5-10 dB 衰减器**（¥10 以内） |
| 4 | 还削波 → 加 **FM 带通滤波器**（88-108 MHz BPF，淘宝 ¥30-50） |

## 6. 升级路线

| 升级 | 投入 | 收益 |
|------|------|------|
| SDR# / CubicSDR 装上 | ¥0 | **看 RDS 文字**（性价比最高） |
| FM 88-108 MHz 专用偶极子（拉杆长 ~75 cm × 2） | ¥30-50 | λ/2 真正对上，信号 +3-5 dB |
| FM 带通滤波器（88-108 MHz BPF） | ¥30-50 | 滤掉 118+ MHz 强信号互调，避免削波 |
| 5-10 dB 固定衰减器 | ¥10 | 信号过强时塞进去 |
| 室外 FM 天线（八木 / 圆极化） | ¥100-300 | 离窗边用，信号 +5-10 dB |

> 💡 **V4 用户注意**：V4 tuner 在 FM 段有镜像问题（88-108 MHz 和 118-138 MHz 互为镜像），**加 BPF 后镜像抑制改善 20+ dB**，FM 段表现会明显提升。
