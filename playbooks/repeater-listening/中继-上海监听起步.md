# HAM 中继台监听起步（上海）

> **适用**：RTL-SDR Blog **V4** (R828D, 24 MHz – 1.766 GHz) + 偶极子 / 单极子天线，居家 SDR++ 监听 VHF/UHF HAM 中继台
> **位置**：上海普陀（距市区 5 km、虹桥 ~15 km、佘山 / 松江方向中继 ~40 km）
> **目标**：稳定听清上海本地活跃中继的语音 + 学会从频谱上识别中继特征
> **最后更新**：2026-08-07
> **注意**：本文**只覆盖接收**。发射需要 A 类操作证 + 指配呼号 + 收发信机（详见 §6）

---

## 0. 中继台是什么（一句话版）

**装在高处的双工转发站**：你发一个频率给它，它**同时**用另一个频率把信号转发出去。

```
你(手台 5W)                中继台(山顶/高楼, 25-50W+高天线)
   |                              |
   |-- 144.640 MHz (上行 Input)-->| RX
   |                              | 全双工转发
   |<-- 145.240 MHz (下行 Output)-| TX
                                   |
                            → 整个城市都能听到
```

为啥要用：**绕开遮挡**。你的 5W 直线打不到对方，但你能打到山顶的中继；中继位置高，50W 能覆盖半个上海。

为啥对 SDR 玩家重要：**你只听下行就能"坐在中继室里"**，跟中继两端的人一起 QSO 的感觉，但不用执照。

## 1. 推荐频点

### 1.1 必听（开箱即有内容）

| 频段 | 中继下行常见区段 | 备注 |
|------|----------------|------|
| **2m VHF** | **145.200 – 145.800 MHz** | 国内 2m 中继下行最密集的区段，12.5 kHz 步进扫 |
| **70cm UHF** | **438.000 – 440.000 MHz** | 国内 70cm 中继下行区段，12.5 kHz 步进扫 |

> **只要听下行**。上行是中继在收、你不需要关心；你想"双收"对比才需要同时扫上行。

### 1.2 重点扫频（开扫策略）

**2m 段（144.000 – 148.000 MHz）**：
- 起点：**144.000 MHz**
- 步进：**12.5 kHz**（中继信道标准宽度）
- 重点关注：**145.200 – 145.800 MHz**（下行密集区）
- 期望：扫出 **3-8 个持续有信号**的频点

**70cm 段（430.000 – 440.000 MHz）**：
- 起点：**430.000 MHz**
- 步进：**12.5 kHz**
- 重点关注：**438.000 – 440.000 MHz**（下行密集区）
- 注意：**430.000 – 432.000 MHz** 业余业务有发射限制，主用是 432 MHz 以上
- 期望：扫出 **2-5 个信号**

**实操**：SDR++ 调到 **2.4 MSPS sample rate**，**一次能看 2.4 MHz 宽**，鼠标滚轮从 144 慢慢滚到 148，**遇到频谱稳定的"凸起"**停下来听 30 秒，**确认不是瞬时干扰**再记下来。

### 1.3 上海本地中继

> **这份文档不写具体上海中继频点。** 原因：频点 / 亚音 / 状态会变，**过时的频点表比没表更危险**（会让你误以为某个中继活跃，实际已经迁移或关闭）。

**获取真实频点的路径**（按推荐度排序）：

1. **SDR++ 实测** → 自己扫一遍最可靠，结果填到 §7 配置表
2. **CRAC 中国无线电协会业余无线电分会** → 上海分会官方公告
3. **RepeaterBook** → 搜 "Shanghai" / "BY"（国际通用数据库）
4. **本地 HAM QQ 群 / 微信群** → 实时信息（亚音、维护、临时下电）

**扫到稳定信号后**，把下行 / 上行 / 频差 / 亚音 / 位置 / 活跃度填到 §7——那才是你自己的"权威"数据。

## 2. SDR++ 参数配置

### 2.1 必配 4 项（核心）

| 参数 | 值 | 为什么这么配 |
|------|----|------------|
| **Mode** | **NFM**（窄带调频） | 中继都是 FM 调制，但业余信道宽 12.5 kHz，**NFM（不是 WFM）**才对。WFM 是 FM 广播 200 kHz 用 |
| **Bandwidth** | **12.5 kHz** | 中继信道标准宽度。**调到 15 kHz 也能听，但邻道干扰会进；调到 6 kHz 会切掉高频** |
| **Squelch** | **关（−100 dB 或拉到最左）** | 跟 ATC 一样，要看到所有弱信号。**听到信号后再慢慢调上去**，刚压住底噪即可 |
| **Gain** | **20-30 dB 起步** | V4 在 25-35 dB 区间 SNR 最佳。**比 ATC 略低**（ATC 30-40 dB，中继信号比 ATC 强），**比 FM 广播高得多**（FM 广播 0-20 dB） |

### 2.2 强烈建议

| 参数 | 值 | 为什么 |
|------|----|--------|
| **AGC** | **关** | 中继信号有强有弱（基站 vs 远端手台差 20-30 dB），AGC 会把弱信号压平。**必须关** |
| Sample Rate | 2.4 MSPS | 一次看 2.4 MHz 宽频谱，**跨多个中继频点**（间隔才 12.5kHz，2.4 MHz 内能看 192 个信道），便于扫频找活跃中继 |
| FFT Resolution | 2048 | 频谱分辨率 ~1.2 kHz 够用 |

### 2.3 CTCSS 亚音（接收端不用设，了解即可）

中继常用 **67 – 250 Hz** 的亚音频作为"敲门砖"：
- 你的手台如果**不发对应亚音**，中继不转发（防止干扰误触发）
- **接收端不需要设**——亚音在语音频带下方（人耳听不到 / SDR 听得到低频嗡嗡），不影响你听语音
- **SDR++ 原版没有 CTCSS 解码面板**，要在频谱上看到 67-250 Hz 的小尖峰才知道有亚音
- **记录到亚音值**：未来你考 A 类证拿到呼号后，发射时要设对

| 常见亚音值 (Hz) | 国内中继使用频率 |
|----------------|----------------|
| 67.0 / 71.9 / 74.4 | 较少见 |
| 88.5 / 91.5 / 94.8 | ⭐⭐⭐⭐ 常见 |
| 100.0 / 103.5 / 107.2 | ⭐⭐⭐⭐⭐ 上海常见 |
| 110.9 / 114.8 / 118.8 | ⭐⭐⭐ |
| 123.0 / 127.3 / 131.8 | ⭐⭐ |

### 2.4 削波警告

> ⚠️ **中继信号比 ATC 强、比 FM 广播弱**。ATC 用 30-40 dB，FM 广播用 0-20 dB，**中继落在中间 20-30 dB**。
> 削波后频谱两侧冒对称小峰，降 Gain 5 dB 再看。**削波会导致中继转发出来的语音失真**（间接影响：你听到的也是削波后的信号，因为中继 RX 端被削了）。

## 3. 物理准备

### 3.1 天线

**核心矛盾**：中继是**双频段**（2m 145 + 70cm 435），但 V4 loaded whip 设计频段是 VHF，70cm 段需要妥协。

| 方案 | 投入 | 效果 | 推荐度 |
|------|------|------|--------|
| **V4 loaded whip 单极子**（你手头有） | ¥0 | 2m 段 0 to +2 dBi（设计频段内），70cm 段 -3 to -6 dBi（设计频段外） | ⭐⭐ 起步够用 |
| **2m 单段偶极 50cm × 2** | ¥30 | 145 MHz 精准谐振，2m 段 +3-5 dB | ⭐⭐⭐ |
| **70cm 单段偶极 16cm × 2** | ¥30 | 435 MHz 精准谐振，70cm 段 +3-5 dB | ⭐⭐⭐ |
| **双段偶极（diamond X-50 / SRH-701）** | ¥100-300 | 两段同时谐振，方向性增益好 | ⭐⭐⭐⭐⭐ 想长期玩就上 |

**极化**：**已垂直** ✅。V4 loaded whip 是单极子，立着就是垂直极化，**中继需要垂直**——**完美匹配，不需要任何调整**。
- **不要**把天线水平摆放（loaded whip 是单极子，水平放完全失谐）
- **不要**找"两臂"（你只有一根，没有两臂）

**loaded whip 性能拆解**：
- 物理长度 ~20-25cm（含加载线圈）
- 加载线圈在中下部（弹簧状）—— 电学延长到 VHF 段谐振
- 顶端有金属小球（防静电 / 末梢电容）
- 极化：垂直（立着就是）
- 谐振点：VHF 段优化（~100-200 MHz）
- 2m 段（145 MHz）：✅ 设计频段内，增益约 0 to +2 dBi
- 70cm 段（435 MHz）：⚠️ 远高于设计频率，增益约 -3 to -6 dBi
- 吸盘底座当"地"：效果差（桌面 / 窗玻璃不导电），**损失 2-3 dB**

**增益优化（吸盘"地"的坑）**：
- 吸盘下面**贴一片铝箔**（5-10cm 见方），增大有效"地"面积
- 或吸在**金属窗框 / 金属阳台栏杆**上
- **不要**吸在窗玻璃上（玻璃不导电，等于没地）

**位置**：
- 窗边是底线，**越高越好**
- 朝**市区 + 佘山 / 松江方向**（上海本地中继多在这两个方向）
- 离金属 ≥ 30 cm

### 3.2 同轴线

- 原装 3 米那根够用
- 远离 USB 3.0 数据线、电源线
- 不要卷成圈

### 3.3 不同时段的天线选择

| 玩法 | 推荐 |
|------|------|
| 偶尔扫频、不挑频段 | V4 loaded whip，凑合听个响（已垂直，无需调整） |
| 主听 2m 段（推荐起步） | V4 loaded whip，**吸盘下贴铝箔**当"地" |
| 主听 70cm 段 | 单段 70cm 偶极（loaded whip 在 70cm 段偏弱 -3 ~ -6 dBi） |
| 长期玩 / 想考 A 类证发射 | 双段偶极（diamond X-50 / SRH-701 类） |

## 4. 实操流程（按这个顺序来）

1. 打开 SDR++，Source 选 RTL-SDR USB
2. 频点输入 **145.200**，回车（中继下行区段起点）
3. Mode → **NFM**
4. BW → **12.5 kHz**
5. Squelch → 拉到最左（关）
6. Gain → **Manual 25 dB**
7. AGC → **关**
8. Sample Rate → **2.4 MSPS**（看宽频谱）
9. 看频谱：
   - 噪声底应在 **−110 ~ −100 dBm**
   - 中继信号峰跳到 **−80 ~ −60 dBm** 是正常
   - 看到**稳定凸起**（不是瞬时干扰）→ 停下来听
10. 削波（频谱两侧冒小峰）→ 降 Gain 5 dB
11. 没信号 → 升 Gain 5 dB，最高别超 40 dB
12. 听到语音 → **记录**：频点、亚音（如有）、时段时间、典型呼号、内容
13. 鼠标滚轮往上滚 12.5 kHz，**逐个频点扫**，到 145.800 为止
14. 切到 **438.500**，重做 9-13 步（70cm 段）

**进阶**：扫到 3-5 个稳定中继后，**逐个守听 10 分钟**，记录：
- 活跃度（每小时 QSO 数量）
- 典型用户（呼号前缀 / 是否本地）
- 典型时段（早 / 晚 / 周末）
- 是否有网管 / 自动 ID

## 5. 排错

### 5.1 听不到任何信号

| # | 检查项 | 修复 |
|---|--------|------|
| 1 | 频点对不对 | 2m 段扫 145.200-145.800，70cm 段扫 438.000-440.000 |
| 2 | Mode 是不是 NFM（不是 WFM / AM） | 改 NFM |
| 3 | BW 是不是 12.5 kHz（不是 6 kHz / 200 kHz） | 改 12.5 |
| 4 | Squelch 是不是关了 | 拉到最左 |
| 5 | AGC 是不是关了 | 关 AGC |
| 6 | 天线极化是不是垂直 | V4 loaded whip **已是垂直**，**不要水平摆** |
| 7 | 时段对不对 | 晚上 19-22 是高峰，凌晨 3-6 几乎没人 |
| 8 | 你家是不是被屏蔽了 | 换窗边、加 LNA（SPF5189 +20 dB） |

### 5.2 频谱有信号但没声音

| # | 检查项 | 修复 |
|---|--------|------|
| 1 | 频点是不是 12.5 kHz 倍数 | 中继信道 12.5 kHz 步进，145.205 之类频点不在标准位置 |
| 2 | Sample Rate 够不够 | 至少 1.2 MSPS（BW 12.5 kHz 用 0.4 MSPS 就够，但 FFT 不好看） |
| 3 | 是不是邻道干扰 | BW 试 8 kHz / 6 kHz，看是不是串进来的强信号 |
| 4 | Audio 设备选错 | SDR++ Settings → Audio → Output 选对 |

### 5.3 听到声音但不是语音

| # | 可能性 | 特征 |
|---|--------|------|
| 1 | **是 ATC 串扰** | 118-137 MHz 段，V4 tuner 镜像问题。**加 2m BPF 滤波器** |
| 2 | **是 FM 广播互调** | 88-108 MHz 互调到 144+。**加 VHF BPF** |
| 3 | **是干扰** | 持续嗡嗡声 / 莫尔斯码 / 数字信号 | 
| 4 | **中继空闲** | 没人说话，只有底噪 + 中继 ID（每 10 分钟一次） |

### 5.4 听到"咔哒"声

**正常现象**——中继 squelch tail 或用户松 PTT：
- 单次咔哒 = 用户松 PTT
- 持续短促咔哒 = 中继超时掉线
- **不需要处理**，是 FM 中继的正常行为

### 5.5 频谱稳定凸起但听不清语音

| # | 检查项 | 修复 |
|---|--------|------|
| 1 | BW 是不是 12.5 kHz | 调到 12.5 |
| 2 | 削波了 | 频谱两侧对称小峰，降 Gain 5 dB |
| 3 | 信号太弱 | 升 Gain 5 dB，或换窗边 |
| 4 | 是数字模式（DMR / D-STAR） | 听感是"机器人讲话"或嗡嗡声，不是真语音。SDR++ 听不了 DMR，需要装 DSD+ |

## 6. 升级路线

### 6.1 纯监听路线

| 升级 | 投入 | 收益 |
|------|------|------|
| 吸盘下贴铝箔 5-10cm | ¥0 | **"地"反射面 +2-3 dB**（最划算） |
| 2m / 70cm 单段偶极 | ¥30/段 | 谐振精准 +3-5 dB |
| 双段偶极（diamond X-50 / SRH-701） | ¥100-300 | 两段同时谐振，方向性好 |
| SPF5189 宽带 LNA | ¥50-100 | 弱信号 +20 dB |
| VHF BPF (140-150 MHz) | ¥30-50 | 滤掉 FM 广播互调 + ATC 镜像 |
| 室外 5/8λ 垂直天线 | ¥200-400 | 离窗 + 高增益 + 真垂直极化 |

> 💡 **V4 用户优势**：V4 内置 **bias-T**（V3 没有），加 LNA 时直接 SDR++ 软件里开 bias-T 开关就能馈电，**不用额外买 bias-T 注入器**。
