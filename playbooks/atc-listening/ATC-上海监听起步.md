# ATC 监听起步（上海）

> **适用**：RTL-SDR Blog **V4** (R828D, 24 MHz – 1.766 GHz) + 加载单极子天线，居家 SDR++ 监听 VHF 民航 ATC
> **位置**：上海普陀（距虹桥 ~15 km，浦东 ~40 km）
> **目标**：塔台 + 飞机应答都能听清楚
> **最后更新**：2026-08-04

---

## 1. 推荐频点

### 1.1 必听（任何时候都有内容）

| 频点 | 部门 | 说明 |
|------|------|------|
| **121.500 MHz** | 国际应急 | 24h 有值班；不一定每分钟都有人说话，但有信号时永远有内容。ATC 圈里"测试接收"用的就是它 |
| **121.600 MHz** | 大陆通用 Ground | 飞机推出/滑行时最密集。早上 7-10 / 傍晚 5-8 高峰期几乎每分钟都有对话 |

### 1.2 重点扫频

**整段扫**：118.000 – 137.000 MHz，25 kHz 步进。每个机场的 Tower / Ground / Approach / Departure 都在这段里。

- 把 SDR++ 调到 2.4 MSPS sample rate，能看到 2.4 MHz 宽频谱
- 鼠标滚轮扫，或者直接手动输入频点
- 信号最强的几个频点记下来 → 那就是当前最忙的部门

### 1.3 上海机场参考频点

> ⚠️ 频点**会变**，下面只是参考。每次实际收听以最新公开数据为准。

| 频点（参考） | 部门 | 备注 |
|------------|------|------|
| 118.100 / 118.200 / 130.000 | 虹桥 Tower | 起飞降落跑道指挥 |
| 121.600 / 121.700 | 虹桥 Ground | 滑行 |
| 119.750 / 120.800 / 121.800 | 虹桥 Approach / Departure | 进近离场 |
| 118.400 / 121.750 | 浦东 Tower | 起飞降落跑道指挥 |
| 121.600 / 121.700 | 浦东 Ground | 滑行 |
| 119.200 / 120.400 / 125.500 | 浦东 Approach | 进近 |
| 120.600 / 124.050 / 125.625 | 浦东 Departure | 离场 |

**查证方式**（频点会变，**用之前先核对**）：

1. radioReference.com → 搜 "Shanghai" / "China"
2. 国内公众号 / ham 论坛搜"上海 ATC 频率"
3. SDR++ 整段扫，自己建一张表

### 1.4 监听时段推荐

- **早 7-10**：起降高峰，Ground 频最密集
- **晚 5-8**：离港高峰，Tower 频最密集
- **深夜 11-2**：稀少的过境 + 国际航班
- **雨天**：电磁波被雨衰，能听到的明显减少

## 2. SDR++ 参数配置

### 2.1 必配 4 项（核心）

| 参数 | 值 | 为什么这么配 |
|------|----|------------|
| **Mode** | **AM** | VHF 民航国际标准调幅，必须 AM。其他模式（FM/USB/LSB）都解不出 ATC 语音 |
| **Bandwidth** | **6 kHz** | ATC 信道 25 kHz 间隔，语音占 6-8 kHz。6 kHz 是标准；信号弱时改 8 kHz 解调更稳，但会多 2 kHz 噪声 |
| **Squelch** | **关（−100 dB 或拉到最左）** | Squelch 是"门"——门内信号才出。飞机应答是弱信号（比塔台弱 30 dB），开了 Squelch 直接被关在外面。**听弱信号必须关** |
| **Gain** | **30 dB 起步** | V4 tuner 在 30-40 dB 区间 SNR 最佳。先 30 dB，看底部 dB 数调整：削波（出现肩膀）就降 5 dB；没信号就加 5 dB。**别超 45 dB**，再高噪声底抬得比信号快 |

### 2.2 强烈建议

| 参数 | 值 | 为什么 |
|------|----|------|
| **AGC** | **关** | AGC 自动压平强弱信号差。塔台信号强、飞机应答弱，开了 AGC 飞机应答会被自动压低到听不清。**必须关** |
| Sample Rate | 2.4 MSPS | 一次看 2.4 MHz 宽频谱，跨多个 ATC 频点，便于扫频找信号 |
| FFT Resolution | 2048 | 频谱分辨率 ~1.2 kHz 够用 |

### 2.3 可选

| 参数 | 值 | 为什么 |
|------|----|------|
| Frequency correction | 按 V4 实际 ppm 调 | V4 误差 +1 ~ +5 ppm。听 121.500 时若觉得音调偏高/偏低就微调 |
| 噪声抑制 | 0 / 关 | 噪声抑制会削掉弱信号，监 ATC 建议关 |

## 3. 物理准备

### 3.1 天线

- **极化**：**垂直**（V4 出厂的 **loaded whip 单极子**，吸盘当"地"，单棒立着就是垂直极化）
  - **不用刻意摆姿势**，吸盘一吸、单棒指天就是对的
- **长度**：拉杆全伸约 **20-25 cm**（含底部 loading coil）
  - 物理上不到 λ/4（VHF 段 λ/4 = 50-60 cm），靠**加载线圈**电学延长到 VHF 段谐振
  - 增益比偶极子**低 2-3 dB**（吸盘当"地"效果有限）
- **位置**：吸盘吸在**朝机场方向的窗玻璃**上
  - 虹桥在**西南**（光复西路朝南/西南的窗能直对）
  - 浦东在**东南**（朝东/东南的窗直对）
- **离地高度**：越高越好（楼内也能用，窗边是底线）
- **吸盘"地"的坑**：窗玻璃**不导电**，吸盘当"地"效果差
  - 解决：吸盘下面**贴一片铝箔**（5-10 cm 见方），增大有效"地"面积
  - 或吸在**金属窗框**上（如果有）
- **离金属**：≥ 30 cm，避开金属窗框、铝合金窗轨、空调外机（金属会反射/短路 E 场）

### 3.2 同轴线

- 原装 3 米那根够用
- 远离 USB 3.0 数据线、电源线（USB 3.0 在 2.4 GHz 附近有强干扰，谐波到 VHF 段）
- 不要卷成圈（卷起来会形成电感，引入额外损耗）

## 4. 实操流程（按这个顺序来）

1. 打开 SDR++，Source 选 RTL-SDR USB
2. 频点输入 **121.500**，回车
3. Mode → **AM**
4. BW → **6 kHz**
5. Squelch → 拉到最左（关）
6. Gain → **Manual 30 dB**
7. AGC → **关**
8. 看底部 dB 数：
   - 噪声底应在 **−110 ~ −100 dBm**
   - 信号峰跳到 **−60 ~ −80 dBm** 是正常
9. 削波（肩膀出现）→ 降 Gain 5 dB
10. 没信号 → 升 Gain 5 dB，最高别超 45 dB
11. 听到稳定语音后，把吸盘吸到窗玻璃上
12. 切换到 121.600 / 118.100 / 118.400 等频点对比

## 5. 排错：能听塔台但飞机弱

按优先级试：

| # | 动作 | 预期效果 |
|---|------|---------|
| 1 | 找对频点（塔台 vs 飞机应答可能在不同频段） | 飞机应答可能本来就不在你听的频点上 |
| 2 | BW 试 8 kHz | 弱信号解调更稳 |
| 3 | Gain 拧到 35-40 dB | 抬高 ADC 噪声底，让弱信号浮出来 |
| 4 | Squelch 已经关（必须） | 弱信号能进来 |
| 5 | AGC 已经关（必须） | 弱信号不被自动压平 |
| 6 | 天线贴窗朝机场方向 | 减少墙体衰减，方向性增益 |
| 7 | 加 LNA（SPF5189 宽带 LNA +20 dB） | 直接翻 100 倍功率 |

> 物理上塔台比飞机应答**本来就强 30 dB 左右**（功率差 + 天线增益差 + 距离差）。所以飞机弱不全是配置问题，部分是物理规律。

## 6. 升级路线

| 升级 | 投入 | 收益 |
|------|------|------|
| SPF5189 宽带 LNA | ¥50-100 | 弱信号 +20 dB ≈ 100 倍功率 |
| 1090 MHz 专用天线 | ¥100-200 | ADS-B 升级用，ATC 也能凑合 |
| 1090 MHz 滤波器 | ¥50 | 配合 LNA 滤掉带外干扰 |
| 低损耗同轴 RG316 | ¥30/米 | 减少线缆损耗 |

> 💡 **V4 用户优势**：V4 内置 **bias-T**（V3 没有），加 LNA 时直接 SDR++ 软件里开 bias-T 开关就能给 LNA 馈电，**不用额外买 bias-T 注入器**。
