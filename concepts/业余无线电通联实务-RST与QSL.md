# 业余无线电:通联实务(RST 信号报告 与 QSL 卡片)

> 学习笔记 · 整理于 2026-07-16

本篇讲两项通联实务:**RST**(报告对方信号质量的打分系统)和 **QSL 卡片**(确认双方成功通联的凭证)。

---

# 第一部分 · RST 信号报告

RST 是火腿通联时报告对方信号质量的标准"打分系统"。通联接通后双方互报一个 RST 值,告诉对方"我这边收到你的信号怎么样"。既是通联礼仪,也是实用的技术反馈。

---

## 一、RST 是三个维度的缩写

| 字母 | 全称 | 评什么 | 中文 |
|------|------|--------|------|
| **R** | **R**eadability | 可懂度(能听清多少内容) | 可读性 |
| **S** | **S**trength | 信号强度(信号多强) | 信号强度 |
| **T** | **T**one | 音调纯净度(**仅对 CW 电报有意义**) | 音调 |

> 关键:**话务(语音)只报 RS 两位数**(音调 T 对语音无意义);**CW 电报报完整 RST 三位数**。

---

## 二、各维度评分标准

### R —— 可读性(1~5 分)

| R | 含义 |
|---|------|
| 1 | 完全无法辨认 |
| 2 | 偶尔能辨认几个字 |
| 3 | 比较费力才能听懂 |
| 4 | 基本能听懂,略有困难 |
| **5** | **完全清楚,毫无困难** |

### S —— 信号强度(1~9 分)

对应接收机上的 **S 表(信号强度表)** 读数:

| S | 含义 |
|---|------|
| 1 | 几乎听不到 |
| 3 | 微弱 |
| 5 | 尚可 |
| 7 | 较强 |
| **9** | **极强信号** |

> S 就是"振幅 → 功率 → dB → S 表"这条链的终点,直接对应收到信号的强弱(功率大小)。S9 = 信号打满。

### T —— 音调(1~9 分,仅 CW)

评莫尔斯那声"嘀"的纯净度——纯净乐音,还是带交流声/嘶嘶声:

| T | 含义 |
|---|------|
| 1 | 极差,交流声很重、很粗糙 |
| 5 | 带明显交流声 |
| 8 | 接近纯净 |
| **9** | **完美纯净的乐音** |

> 音调差通常说明对方发射机电源滤波不好等技术问题,所以 T 也是一种设备"体检"。

---

## 三、怎么读、怎么报

数字连读即可:

- **话务(语音)**:报两位,如 **"59"**(five nine)= R5 + S9 = 完美信号
- **CW(电报)**:报三位,如 **"599"** = R5 + S9 + T9 = 完美电报信号

```
话务:  5 9      → "你的信号完全清楚、非常强"
        │ │
        R S

CW:    5 9 9    → "清楚、极强、音调纯净"
        │ │ │
        R S T
```

---

## 四、"59" 和 "599":高频黑话

- **"59"**(语音)和 **"599"**(CW)是最理想的报告 = "你信号完美"
- **比赛(contest)**中,不管实际信号如何,几乎清一色报 59 / 599——比赛只图快、图数量,报告走个形式,不一定是真实评价
- **日常通联(ragchew)**里的报告更真实,会如实给 "55""57""439" 等

---

## 五、S 表的"加分":S9 + xx dB

信号强到 S9 以上,用 **dB 增量**表示:

```
S9 + 10 dB    → 读作 "59 加 10"
S9 + 20 dB    → 强信号台常见
S9 + 40/60 dB → 近距离大功率台
```

再次印证 **"S 强度 ↔ 功率 ↔ dB"** 是同一条链——S9 封顶后继续用 dB 往上加。

---

## 六、实例

CW 通联:

```
对方发:  "UR RST 579 579"
含义:    你的信号 → R5(清楚) S7(较强) T9(音调纯净)
```

语音通联:

```
对方说:  "You are 5 and 7"
含义:    R5(清楚) S7(较强)
```

---

## 七、小结

| | 报几位 | 组成 | 满分/完美 |
|---|-------|------|-----------|
| 话务(语音) | 2 位 | R(1-5)+ S(1-9) | **59** |
| CW(电报) | 3 位 | R(1-5)+ S(1-9)+ T(1-9) | **599** |

> 一句话:RST 是火腿给对方信号打的"三项分"——能不能听清(R)、信号多强(S)、音调纯不纯(T,仅电报)。语音报 RS 两位、电报报 RST 三位,"59/599"就是满分,也是通联里最常听到的两个数字。

# 第二部分 · QSL 卡片

## 一、QSL 是什么

**QSL** 来自国际通用的 **Q 简语**(无线电标准缩写码),含义是 **"我确认收到"**(I acknowledge receipt)。

所以 **QSL 卡片(QSL Card)= 一张用来书面确认双方成功通联过一次的卡片**。它是通联的"回执 + 纪念品 + 名片"三合一:两个火腿在电波里聊了一次,事后互寄一张卡,等于说"我确认咱俩那天确实通联上了,这是凭证"。

## 二、卡片上有什么

一面是图案设计(风景、呼号艺术字、个人特色),另一面是通联记录:

| 项目 | 内容 | 例子 |
|------|------|------|
| 呼号 | 双方呼号 | BG2ABC |
| To(致) | 对方呼号 | To: JA1XYZ |
| Date | 通联日期(UTC) | 2026-07-16 |
| Time | 通联时间(UTC 世界时) | 1230 UTC |
| Freq/Band | 频率或波段 | 14.025 MHz / 20m |
| Mode | 通联模式 | CW / SSB / FT8 |
| RST | 给对方的信号评分 | 599 |
| QTH | 电台所在地 | Beijing |

> 时间用 **UTC(协调世界时)** —— 全球火腿统一用 UTC,避免时区混乱。

## 三、为什么热衷收集

1. **通联的"战利品"和回忆**:每张卡代表一次真实的空中相遇,贴满一墙就是你的"电波足迹地图"。
2. **申请奖状的凭证 ⭐**(最实际的用途):

| 著名奖状 | 要求 |
|----------|------|
| DXCC | 通联满 100 个国家/地区,每个要 QSL |
| WAS | 通联美国全部 50 个州 |
| WAC | 通联全部 6 大洲 |
| WAZ | 通联全部 40 个 CQ 分区 |

> 想拿 DXCC 这类硬核勋章,就得攒够对应 QSL 卡 —— 这也是很多人追稀有前缀的动力。

3. **收藏与美学**:不少卡片设计精美,本身就是收藏品。

## 四、怎么交换 —— 三种途径

| 途径 | 方式 | 特点 |
|------|------|------|
| 直接邮寄(Direct) | 直接寄对方地址 | 最快,但要付国际邮费(常附回邮资) |
| QSL 局(Bureau) | 通过各国协会卡片局批量转寄 | 便宜,但很慢(几个月到几年) |
| 电子(eQSL / LoTW) | 网上电子确认 | 免费即时,现代主流 |

**LoTW(Logbook of The World)**:ARRL 运营的官方电子 QSL 系统。双方上传通联记录,系统自动比对,匹配上即算一次"确认的 QSL",可直接用于申请 DXCC 等官方奖状,不用寄实体卡。现在很多人"实体卡收藏 + LoTW 拿奖状"两条腿走路。

## 五、一张 QSL 卡串起全部知识

```
QSL 卡片信息         ← 对应学过的
─────────────────────────────────
呼号 BG2ABC          ← 《呼号组成与国际前缀》
Freq 14.025 MHz/20m  ← 《波长频率与频段》
Mode CW              ← 《通信模式与调制》
RST 599              ← 本篇第一部分
Date/Time UTC        ← 全球统一用 UTC
```

> 一句话:QSL 卡片是火腿之间"我们确实通联过"的浪漫凭证 —— 既是挂满墙的世界通联纪念,也是申请 DXCC 等成就奖状的官方证据。

---

## 关联

- 信号强度 S 与《通信模式与调制》里"振幅 → 功率(P∝A²)→ dB → S 表"是同一条链
- 音调 T 只对 CW(等幅电报)有意义,见《通信模式与调制》CW 章节
- QSL 卡上的每一项(呼号 / 频率 / 模式 / RST / UTC)分别对应四篇文档,是整套基础知识的综合应用
