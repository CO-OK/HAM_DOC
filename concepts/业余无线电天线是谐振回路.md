# 业余无线电:天线是一个谐振回路

> 学习笔记 · 整理于 2026-07-20

上一篇《天线原理》从"电波推电子"讲了天线怎么收信号。本篇换一个视角:**天线本质上是一个"摊开在空间里"的 LC 谐振回路。** 理解这点,"长度要匹配波长""天线调谐""驻波比"这些说法就全串起来了。

## 一、先回忆:什么是 LC 谐振回路

电路里,一个**电感 L**(线圈)和一个**电容 C**(两块极板)接在一起,能量会在两者之间来回倒,形成振荡:

```
电容充满电 ──放电──→ 电流流过电感 ──→ 电感建立磁场
      ↑                                    │
      └───充电←── 磁场消失又推电流回来 ←──────┘
```

这个来回倒的节奏,就是**谐振频率**:

$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

- 外来信号频率 **$= f_0$** → 越推越猛(共振),电流最大
- 频率 **$\neq f_0$** → 推不到点上,响应很弱

> 收音机选台,调的就是这个 $C$(可变电容),让 $f_0$ 对准某个电台频率。这就是"谐振回路选频"。

### 澄清:"振荡"就是"来回往复"

上面反复说的**振荡**,不是能量单向流走,而是**周期性地来回重复**。在 LC 回路里,来回的是能量,以及体现能量的**电流方向**和**电荷**:

```
① 电容充满电(能量全在电场里,电流=0)
       │ 放电
       ↓
② 电流最大(能量全在电感磁场里)     电流方向:→
       │ 磁场维持电流,给电容反向充电
       ↓
③ 电容又充满(极性反了)
       │ 反向放电
       ↓
④ 电流最大(方向反过来)            电流方向:←
       │
       └──→ 回到 ①,循环……
```

- 电流:**→ 然后 ←**,来回换向
- 电荷:电容**这边正 → 那边正**,来回搬
- 能量:**电场 ↔ 磁场**,来回倒

一个完整"来回" = 一个**周期**;**每秒来回多少次 = 频率**。

```
电流 ↑
  →  │   ╱‾╲          ╱‾╲
  0 ─┼──╱────╲──────╱────╲──→ 时间
  ←  │ ╱       ╲__╱       ╲
       └─一个来回=一个周期─┘   每秒几个来回 = f (Hz)
```

> 反面对照:电池给灯泡供的**直流**是电流一直朝一个方向流——不来回、不振荡;电波、交流电、LC 回路里的都是**来回 = 振荡**。天线里"电子被电波推着来回跑"就是同一种振荡,7 MHz 即每秒来回 700 万次。

### 谐振频率的单位

$f_0$ 是频率,单位就是**赫兹 Hz(= 1/秒,每秒来回几次)**。

| 量 | 符号 | 单位 |
|----|------|------|
| 电感 | $L$ | 亨利 H |
| 电容 | $C$ | 法拉 F |
| 谐振频率 | $f_0$ | **赫兹 Hz** |

量纲上 $\sqrt{LC}$ 的单位正好是**秒**,取倒数即 $1/\text{秒}=\text{Hz}$。常用换算:$1\,\text{kHz}=10^3$、$1\,\text{MHz}=10^6$、$1\,\text{GHz}=10^9\,\text{Hz}$。

> ⚠️ **代公式的坑**:算 $f_0$ 时 $L$、$C$ 必须用基本单位(H、F),不能直接塞 μH、pF。如 $L=2\,\mu H=2\times10^{-6}$ H、$C=100\,pF=100\times10^{-12}$ F,算出来才是正确的 Hz。另注意区分频率 $f_0$(Hz)与角频率 $\omega_0=2\pi f_0$(rad/s),差一个 $2\pi$。

## 二、天线其实也有 L 和 C——只是"看不见"

一根天线看着就是根金属棒,哪来的电感、电容?它们藏在导体的**物理形态**里,叫**分布参数**:

```
天线导体本身 ──── 有长度、电流流过会产生磁场 → 天生带电感 L
导体两端/对地 ──── 两段金属隔空相对,能存电荷  → 天生带电容 C
```

| LC 电路(集总参数) | 天线(分布参数) |
|--------------------|------------------|
| L = 绕好的线圈 | 导体自身电流产生磁场 → 等效电感 |
| C = 做好的电容器 | 导体两端、导体对大地隔空存电荷 → 等效电容 |
| L、C 是独立零件,看得见 | L、C **均匀分布在整根导体上,分不开、看不见** |

所以天线不是"没有 LC",而是 **L 和 C 摊在整根金属上、和空间融为一体**。它照样满足

$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

只不过这里的 $f_0$ 不由零件决定,而由**天线的长度和形状**决定。

## 三、"长度匹配波长" = "谐振回路调对了频率"

《天线原理》里讲的"半波振子长度 = λ/2 才收得最强",换成谐振回路的语言就是:

```
天线长度对 → 分布 L、C 配出的 f₀ 恰好 = 电波频率 → 共振 → 电流最大
天线长度错 → f₀ 偏离电波频率 → 失谐 → 电流很弱
```

这是**同一件事的两种说法**:

| 说法 A(驻波视角·上一篇) | 说法 B(谐振回路视角·本篇) |
|--------------------------|----------------------------|
| 长度 = λ/2,反射波同相叠加 → 共振 | 长度定下 L、C → $f_0$ 对准电波 → 谐振 |
| 电子来回荡"合上拍子" | LC 能量来回倒"合上拍子" |
| 靠**裁长度**共振 | 靠**长度决定的 $f_0$** 谐振 |

```
电波频率 = 天线 f₀  →  越推越猛,能量高效灌进天线   ▁▂▃▅▇█  强
电波频率 ≠ 天线 f₀  →  推不到点上,大部分被反射掉    ▇▅▂▁▁▁  弱
```

## 四、由此看懂:天线调谐

既然天线是谐振回路,让它"对准频率"就有两条路——**和收音机选台是同一个道理**:

| 手段 | 做法 | 好比收音机 |
|------|------|-----------|
| 裁天线长度 | 把振子剪到 λ/2 | 做一个固定 $f_0$ 的 LC |
| 天线调谐器(ATU) | 外加可调 L/C,把整体 $f_0$ 拽到工作频率 | 转旋钮调 C 选台 |

火腿口头常说"天线要**谐振**在某频率""用调谐器把天线**调谐**过来",用的就是谐振回路这套词。而"调得好不好",最终由下面的**阻抗 → 反射 → 驻波比**这条链量化。

## 五、阻抗:谐振回路"对电流的总阻碍"

要讲清"调得好不好",先要有**阻抗**这个概念。

### 5.1 从电阻到阻抗

直流里阻碍电流的是**电阻 R**(欧姆定律 $U=IR$,单位 Ω),它只把电能变成热。但天线里都是**交流**,除了电阻,还有两个"只存能量、不耗能"的阻碍者——电感和电容,它们的阻碍**和频率有关**:

```
交流电路的阻碍
├── 电阻 R      —— 真消耗能量(变热/辐射),与频率无关
├── 电感的阻碍   —— 感抗 XL = 2πfL,频率越高越挡,不耗能(存磁场)
└── 电容的阻碍   —— 容抗 XC = 1/(2πfC),频率越低越挡,不耗能(存电场)
```

感抗、容抗合称**电抗 X**。

| | 阻碍谁 | 随频率 | 耗能吗 |
|---|-------|--------|--------|
| 电阻 R | 一切电流 | 无关 | **耗**(变热/辐射) |
| 感抗 $X_L$ | 电流变化 | 越高越挡 | 不耗(存磁场) |
| 容抗 $X_C$ | 稳定直流 | 越低越挡 | 不耗(存电场) |

### 5.2 阻抗 Z = 电阻 + 电抗

把"耗能的电阻"和"不耗能的电抗"合成一个复数,就是**阻抗 Z**(单位仍是 Ω):

$$Z = R + jX \qquad |Z| = \sqrt{R^2 + X^2}$$

- **实部 R**:真消耗/辐射掉能量的部分
- **虚部 X**(电抗):只来回存放能量、不消耗的部分($j$ 是虚数单位,电工用 $j$ 不用 $i$)

```
     |Z|
      ╱|
    ╱  | X(电抗:只存不耗)
  ╱____|
   R(电阻:真耗能)
```

> 眼熟吗?这和《电离层与短波传播》第六节的**复折射率 $n=n_实+i\,n_虚$** 是同一套数学思路:**用一个复数,实部管"真损耗",虚部管"只存不耗"。** 阻抗就是电路版的复数量。

### 5.3 谐振的真正含义:电抗归零

《天线是谐振回路》讲的"谐振",用阻抗语言说就是:**感抗和容抗恰好抵消,$X=0$,阻抗变成纯电阻。** 而这个纯电阻正好设计成接近 **50Ω**:

| 状态 | 阻抗 Z | 结果 |
|------|--------|------|
| **谐振** | 纯电阻 ≈ 50Ω($X=0$) | 和 50Ω 电缆/电台**匹配** |
| 天线偏短 | 带容抗(容性) | 失配 |
| 天线偏长 | 带感抗(感性) | 失配 |

> 所以"调天线"本质是:**调长度让电抗 $X$ 归零、让阻抗变成 50Ω 纯电阻**。这把"谐振"和"匹配"焊成了一件事:**谐振 ⇒ X=0 ⇒ 纯 50Ω ⇒ 匹配**。

### 5.4 为什么偏偏是 50Ω

不是天线天生 50Ω,而是**整个系统人为统一到 50Ω 当标准**:同轴电缆在"损耗最小(≈77Ω)"和"承受功率最大(≈30Ω)"之间折中取了 **50Ω**;于是电台、电缆、天线、接头全按 50Ω 造,阻抗一致才不反射。(电视/广播那套是 **75Ω** 体系,另一标准。)

## 六、反射:阻抗一"突变"就弹回一部分

### 6.1 水管类比

想象水在管里流,末端接不同东西:

```
① 末端管口粗细一致  →  水顺畅流出去          无反射
② 末端突然堵死(墙) →  水撞墙弹回、往回涌     全反射
③ 末端接更细的口     →  一部分挤出、一部分弹回  部分反射
```

**电缆里的功率就是"水",天线是"末端"。** 天线阻抗 = 电缆(都 50Ω)= 管口一致,功率顺畅出去;天线阻抗不对 = 管子突然变粗/变细/堵住,一部分功率**弹回来**。

> 关键直觉:**反射不是天线"拒收",而是"路突然变了"**——波在"特性突变的界面"处无法全部通过,只能退回一部分。

### 6.2 这是波的通用定律

任何波(水波、声波、光、电波),**只要传播介质的"特性"突然改变,就在突变处部分反射**。电缆里这个"特性"就是 50Ω 特征阻抗:

| 场景 | 波 | 突变界面 | 反射 |
|------|----|---------|------|
| 山谷回声 | 声波 | 空气→山壁 | 声音弹回 |
| 照镜子 | 光 | 空气→镀银玻璃 | 光弹回 |
| 电离层打全球 | 电波 | 大气→电离层($n$ 突变) | 电波弹回地面 |
| **天线失配** | **电缆里的电波** | **50Ω→天线异常阻抗** | **功率弹回电台** |

> 这正呼应《电离层》第六节:那里波遇**折射率 $n$** 突变而反射;电缆里波遇**阻抗 $Z$** 突变而反射——**"突变界面处部分反射"是同一条定律**,只是突变的量一个是 $n$、一个是 $Z$。

### 6.3 反射了多少:反射系数 Γ

界面两边阻抗差越大,反射越狠。设电缆 $Z_0=50Ω$、天线 $Z_L$:

$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}\,,\qquad \text{反射功率占比} = |\Gamma|^2$$

```
Z_L = 50Ω(相等)  → Γ = 0   → 不反射,全进天线   ✓
Z_L = 150Ω          → Γ = 0.5 → 反射一半电压
Z_L = 0(短路)     → Γ = -1  → 全反射(反相)
Z_L = ∞(开路)     → Γ = +1  → 全反射(同相)
```

$\Gamma=0$ 表示两边一样、**没有界面** → 不反射;$|\Gamma|=1$ 表示短路/开路,**功率一点进不去** → 全弹回。

## 七、驻波比 SWR:反射的"体检指标"

### 7.1 驻波怎么形成

弹回的波沿电缆往回跑,和还在往前的入射波**叠加**,形成看起来不动的**驻波**:

```
入射波 →→→→→→→→
反射波 ←←←←←←←←
────────────
叠加 = 驻波:某些点老是最大(波腹),某些点老是最小(波节)

电压 ↑
 │  ╱‾╲    ╱‾╲    ╱‾╲     ← 波腹(Vmax)
 │ ╱   ╲  ╱   ╲  ╱   ╲
 │╱     ╲╱     ╲╱     ╲   ← 波节(Vmin)
 └────────────────────→ 沿电缆的位置
```

完全匹配(无反射)时电缆各点电压一样大,**没有驻波**。

### 7.2 SWR 的定义

**驻波比 SWR(也叫 VSWR)= 电缆上电压最大值 ÷ 最小值**,用"驻波起伏多大"量"反射多严重":

$$\text{SWR} = \frac{V_{\max}}{V_{\min}} = \frac{1+|\Gamma|}{1-|\Gamma|}$$

SWR 永远 $\ge 1$,越接近 1 越好。

| SWR | \|Γ\| | 反射功率 | 进天线功率 | 评价 |
|-----|-------|----------|------------|------|
| 1.0:1 | 0 | 0% | 100% | 完美 |
| 1.5:1 | 0.20 | **4%** | 96% | 很好 |
| 2.0:1 | 0.33 | **11%** | 89% | 可接受(常见上限) |
| 3.0:1 | 0.50 | **25%** | 75% | 偏高,该调 |
| 5.0:1 | 0.67 | **44%** | 56% | 差 |
| ∞ | 1.0 | 100% | 0% | 开路/短路,危险 |

> 注意:SWR 2:1 只反射 11%,没想象中可怕——**新手常过度追求 1:1**。真正的危害在下面。

### 7.3 SWR 高有什么害处

| 害处 | 说明 |
|------|------|
| **功率白费** | 反射功率没辐射出去,效率下降(但 2:1 只损 11%,有限) |
| **可能烧功放** | 反射波打回发射机末级;现代电台会**自动降功率保护(折返)**,太高直接不让发 |
| **馈线损耗放大** | 波在电缆里来回跑,损耗按往返算,长线 + 高 SWR 更明显 |

经验阈值:

```
SWR < 1.5 : 优秀,不用管
1.5 ~ 2.0 : 良好,正常用
2.0 ~ 3.0 : 偏高,建议调天线
> 3.0     : 别硬发,先调(很多电台此时自动折返/罢工)
```

### 7.4 SWR 高了怎么办

| 手段 | 原理 |
|------|------|
| **裁天线长度** | 把天线调回谐振,阻抗回到 50Ω(改长度定 $f_0$) |
| **天线调谐器 ATU** | 加可调 L/C 把失配"变换"回 50Ω(第四节那两条路之一) |
| **换工作频率** | 移到天线谐振点附近再发($f_0$ 对上就低 SWR) |
| **检查馈线/接头** | 进水、氧化、断线都会让 SWR 异常 |

> ⚠️ **ATU 是"骗"电台的**:它让电台端看到 50Ω(表显 SWR=1),但 ATU 到天线那段电缆上驻波依然存在。它解决的是"保护电台、让机器肯出力",**不是真把天线调谐了**。治本还是把天线本身弄谐振。

### 7.5 怎么测

驻波表 / 天线分析仪串在电台与天线之间直接读数(现代电台多内置)。调天线时边调长度边看,找 SWR 最低点 = 谐振点:

```
调长度找谷底:
SWR │╲              ╱
    │ ╲            ╱
    │  ╲___▁▁▁___╱      ← 谷底 = 谐振频率,SWR 最低
    └────┼─────────→ 频率
       天线谐振点
```

## 八、集总 LC 与天线对照总表

| | 集总 LC 谐振回路 | 天线(分布谐振回路) |
|---|------------------|----------------------|
| 电感 L 来自 | 线圈 | 导体电流产生的磁场 |
| 电容 C 来自 | 电容器 | 导体间/对地隔空存电荷 |
| $f_0$ 由谁定 | L、C 元件值 | 天线**长度与形状** |
| 怎么调频率 | 转可变电容 C | 裁长度 / 加天线调谐器 |
| 共振时 | 回路电流最大 | 感应/辐射电流最大,收发最强 |
| 能量去向 | 在 L、C 间来回倒 | 大部分**辐射到空间**(这才是目的) |

> **一个关键区别**:集总 LC 是为了"储能振荡",能量困在回路里;天线是"故意设计成把能量辐射出去"的谐振回路——它谐振的目的不是自己振,而是**高效地把电流能量泼向空间(发射)、或把空间的电波能量收进电流(接收)**。

## 九、一条链收束:谐振 → 阻抗 → 反射 → SWR

```
天线谐振(长度对) → 电抗 X=0 → 阻抗=50Ω → 界面消失 → Γ=0 → 无反射 → SWR≈1  ✓
天线失谐(长度错) → 带电抗 X → 阻抗≠50Ω → 有突变界面 → 反射 → 驻波 → SWR 高  ✗
```

> **天线 = 一个"摊开在空间里"的 LC 谐振回路**:靠长度/形状定 $f_0$,频率对上就共振、收发最强。而"调得好不好"最终由 **SWR** 量化——谐振 ⇒ 电抗归零 ⇒ 纯 50Ω ⇒ 无反射 ⇒ SWR≈1。谐振、阻抗、反射、SWR 是同一件事的四层皮:**谐振是因,阻抗匹配是机制,反射是现象,SWR 是读数**。治本靠裁长度/换频率让天线真谐振,应急靠 ATU 保护电台。
