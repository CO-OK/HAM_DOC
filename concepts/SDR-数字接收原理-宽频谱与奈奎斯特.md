# SDR 数字接收原理：宽频谱与奈奎斯特定理

> **一句话总结**：普通收音机用死的模拟滤波器一次只能选一个频率；SDR 用 ADC + FFT 把整段频谱"采下来 + 算出来"，所以能同时看到很宽的频率范围。而这背后能成立的根本约束是**奈奎斯特定理**。

---

## 第一部分：为什么 SDR 能看到宽频段

### 1. 核心问题不是"宽"，是"同时"

普通收音机不是"接收能力不够宽"——它在任何时刻**只能选一个频率**。你转旋钮，物理上就在换滤波器。

SDR 也不是"接收能力更强"——它是**同时把整段频谱采下来，然后数学上拆开**。

### 2. 棱镜 vs 滤镜：最直观的类比

| | 普通收音机 | SDR |
|---|---|---|
| 本质 | 天线上的电压 = 所有频率叠加的"白光" | 同上 |
| 处理方式 | **滤镜**：只让一种颜色通过 | **棱镜**：一次把所有颜色分开 |
| 看到啥 | 一次一种 | 一次所有 |

**关键认知**：天线上的电压，**本来就是**所有频率的叠加。ADC 不需要"接收宽频段"——它**只测电压**。

### 3. 普通收音机：超外差原理

超外差 = **Super-Heterodyne**，把任意频率的信号"搬"到一个固定中频 (IF) 上处理。

```
天线 → [RF放大] → [混频器] ← [本振LO]  ← 你转的旋钮
                  ↓                ↑
                减法：中频 = LO - f_signal
                  ↓
              [中频滤波器]  ← 物理滤波器，固定带宽（比如 455 kHz AM、10.7 MHz FM）
                  ↓
              [检波/解调] → 喇叭
```

**关键**：
- 中频滤波器是个**陶瓷/晶体做的窄带模拟滤波器**，只让 455 kHz ± 几 kHz 通过
- 想听别的台 → 只能转旋钮 → 改变本振 LO 的频率 → 把那个台"搬"到 455 kHz
- **滤波器是物理的，搬不走、改不了、死焊在板上的**

所以"调台" = 调本振。但任何时刻，喇叭里**只有一个频率**。

### 4. SDR：宽带数字接收

```
[宽带天线] → [宽带低噪放LNA] → [ADC直接采样] → [数字信号处理]
              ↑                ↑                ↑
            RF 进来          整段带宽        用数学拆开
            (整个频段)       一次性量化       (FFT + DDC)
                                            ↓
                                    [频谱显示 + 解调]
```

**关键三步**：

#### 4.1 宽带 ADC 采样

ADC 干的事极其简单：每秒问 N 次"现在电压多少"，然后吐出一长串数字。

```
t=0.0000 μs: 电压 = 0.123 V  → 输出 0.123
t=0.4167 μs: 电压 = 0.456 V  → 输出 0.456
t=0.8333 μs: 电压 = -0.234 V → 输出 -0.234
...
```

RTL-SDR 的 ADC 速度是 **2.4 MSPS**（每秒 240 万次）。它干的事就是：**每秒问 240 万次"现在电压多少"**，然后吐出一长串数字。

```
[0.123, 0.456, -0.234, 0.789, -0.123, ...]   ← 一串数字（时域）
       ↑
       这串数字里同时包含了所有频率的信息
```

**ADC 不需要"调谐"**。它就是忠实地测量每一瞬间的电压，不管那个电压是 100 MHz 还是 101 MHz 叠出来的。

#### 4.2 FFT（快速傅里叶变换）—— 数学分光镜

拿到这串数字以后，FFT 做了一件事：

> **给我一串时间序列，告诉我这串时间里有哪些频率、各占多大。**

数学上的事实：**任何复杂的波形 = 一些正弦波的叠加**。FFT 就是那个"找出原始正弦波"的算法。

```
时域（ADC 输出的）            频域（FFT 算出来的）
v(t) = 一团混在一起的电压  →  X(f) = {100 MHz: 0.5, 101 MHz: 0.3, ...}
   ↑                              ↑
   你看到的                      频谱图上看到的东西
```

**一次 FFT = 同时告诉你这一瞬间每个频率的强度**。所以频谱图（横轴频率、纵轴强度）就是 FFT 输出的可视化。

#### 4.3 DDC（数字下变频）选台

FFT 给你的是"全景"，但解调一个具体电台还是要把那个频率**搬到基带**。
- 传统：靠本振 + 模拟混频器搬
- SDR：用**数字乘法** + **数字低通滤波器**搬（软件里算）
- 所以你点击频谱图上的某个频率，DDC 立刻把那个信号搬到 0 Hz 解调

### 5. 关键差异表

| 维度 | 普通收音机（超外差） | SDR++（宽带数字接收） |
|---|---|---|
| 一次能处理的频谱 | 一个频率点 | 一整段带宽（RTL-SDR ≈ 2.4 MHz） |
| "选台" 怎么做 | 旋钮调本振，搬信号到固定中频 | FFT 后用数字下变频 (DDC) 选 |
| 滤波器 | 模拟陶瓷/晶体中频滤波器（物理的、死的） | 数字滤波（数学算出来的） |
| 频谱显示 | 调谐表指针，单点 | 整个带宽内的频谱 + 瀑布图 |
| 改变带宽 | 换滤波器硬件 | 改一个数字参数 |

**本质区别**：模拟滤波器是"做一个只能通过某个频段的电路"，数字 FFT 是"**算**出整段时间里有哪些频率、各多大"。后者只需要算力，不需要物理滤波器。

### 6. 反直觉的澄清：SDR 不是无限宽

很多人以为："SDR 接收 100 MHz 的信号，那 ADC 就要采 100 MHz"——错。

**奈奎斯特说的是**：如果你想"无失真"地表示一个 100 MHz 的信号，ADC 至少要采 200 MSPS（每秒 2 亿次）。这根本做不到。

SDR 实际怎么做的？**先下变频到低中频**。RTL-SDR 内部有个 R820T 调谐器，它**先把 100 MHz 混频到 ~3.5 MHz 的中频**（这一步是模拟的、本振可调的，但只是把整段"搬下来"），然后 ADC 采这个 3.5 MHz 的中频。2.4 MSPS 采 3.5 MHz 带宽——奈奎斯特说 1.2 MHz 够用——所以 R820T 内部的中频大概是 0-2.4 MHz 的一段。

```
外部 100 MHz 信号  →  R820T调谐器(模拟混频+本振)  →  中频 0-2.4 MHz
                                                       ↓
                                                  ADC 采这个中频
                                                       ↓
                                                  FFT 分析
```

**这一步的模拟混频是必要的**（因为 ADC 速度不够直接采 100 MHz），但 R820T 一次搬下来的就是 2.4 MHz 宽的一整段，不是一个频率。**所以本质上还是"宽带"**。

### 7. SDR 实际带宽受限于硬件

| 设备 | 采样率 | 瞬时带宽 |
|---|---|---|
| RTL-SDR | 2.4-3.2 MSPS | ~2.4 MHz |
| Airspy R2 | 10 MSPS | ~10 MHz |
| HackRF One | 20 MSPS | ~20 MHz |
| USRP | 几十 MSPS | 几十 MHz |

## 第二部分：奈奎斯特定理

### 1. 一句话

> **要无失真地表示一个信号，采样率必须至少是信号最高频率的 2 倍。**

### 2. 为什么是 2 倍（直觉）

想象你在"采样"一个正弦波：

```
✅ 采样率足够（每周期 ≥ 2 个点）：
   正弦波：   ⌢⌣⌢⌣⌢⌣⌢⌣⌢⌣
   采样点：   •   •   •   •   •
              ↑波峰 ↑波谷
   → 你拿到这些点，连起来，**能还原**原来的正弦波

⚠️ 临界（每周期正好 2 个点）：
   正弦波：   ⌢⌣⌢⌣⌢⌣⌢⌣
   采样点：   ↑   ↑   ↑   ↑
              都采到过零点
   → 知道是啥频率，但**不知道相位**（从哪儿开始的）

❌ 采样率不够（每周期 < 2 个点）：
   正弦波：   ⌢⌣⌢⌣⌢⌣⌢⌣⌢⌣
   采样点：   •           •           
              ↑           ↑
              都采到正峰 → 看起来像 DC（直流）
   → **完全错**——高频被"折叠"成了低频
```

**为什么 2 个点？** 一个完整周期 = 一次起伏 = 至少要采到"最高"和"最低"两点，才能确认这是一个完整的波。少一个就分不清是"高频小波"还是"低频大波"。

### 3. 公式

$$f_s \geq 2 \cdot f_{max}$$

- $f_s$ = 采样率（每秒采多少点）
- $f_{max}$ = 信号里最高的频率

反过来，已知采样率，**能看的最高频率**叫**奈奎斯特频率**：

$$f_{Nyquist} = \frac{f_s}{2}$$

### 4. 混叠 (Aliasing)：不够采样会怎样

这是奈奎斯特定理**真正在防的坑**——当采样率不够时，**高频信号会被"折叠"成低频信号**，而且看起来跟真实低频**一模一样**。

```
原始信号：高频 ∿∿∿∿∿∿∿∿∿∿∿∿ （比如 5 MHz）
采样率：低（只采 1 点/周期）
看到的：低频 ∿~~∿~~∿~~∿ （比如 1 MHz）
              ↑
              错的！高频被当成低频了
```

**反过来的灾难**：你以为自己在听 1 MHz 的电台，实际是 5 MHz 某个干扰源被混叠下来的。**SDR 里这种坑很常见**——所以 ADC 前面一定要加**抗混叠滤波器**（低通滤波器，把 f > f_Nyquist 的频率全部砍掉）。

### 5. 在 SDR 里的实际意义

| 参数 | RTL-SDR | Airspy R2 | HackRF One |
|---|---|---|---|
| 采样率 | 2.4-3.2 MSPS | 10 MSPS | 20 MSPS |
| **奈奎斯特频率** | **1.2-1.6 MHz** | **5 MHz** | **10 MHz** |
| 实际能看的带宽 | ~2.4 MHz | ~10 MHz | ~20 MHz |

**所以 RTL-SDR 一次能看到 2.4 MHz 宽的频谱，本质上就是：ADC 采 2.4 MSPS，能无失真表示的最高频率是 1.2 MHz，整段带宽就是 2.4 MHz**（注意是 f_s 带宽，因为 IQ 采样实际带宽 = f_s，比 f_Nyquist 大——这个后面再讲）。

### 6. 两个容易混的概念

| 概念 | 含义 |
|---|---|
| **奈奎斯特速率** | 采一个信号**至少**需要的采样率（2 × f_max） |
| **奈奎斯特频率** | 一个采样率**能采的最高**频率（f_s / 2） |

**举例**：ADC 2.4 MSPS
- 奈奎斯特频率 = 1.2 MHz（这是 f_s / 2）
- 想采 1 MHz 的信号，奈奎斯特速率 = 2 MSPS（这是 2 × f_max）→ 2.4 MSPS 够了 ✓

## 总结

| 概念 | 核心 |
|---|---|
| **SDR 看宽频段** | ADC 是个不问频率的快电压表，FFT 是个数学分光镜，两者配合自然能同时看到整段频谱 |
| **模拟 vs 数字** | 模拟滤波器 = 死的硬件，一次一个频率；数字 FFT = 活的数学，一次所有频率 |
| **奈奎斯特定理** | 采样率 ≥ 2 × 最高频率，否则高频会被"折叠"成低频（混叠），数字信号处理就崩了 |
| **SDR 实际带宽** | 受限于 ADC 采样率（RTL-SDR 2.4 MSPS → ~2.4 MHz 瞬时带宽） |
| **SDR 内部结构** | R820T 模拟下变频到中频 → ADC 采中频 → FFT 分析，本质上仍是宽带 |
